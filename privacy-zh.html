私隱政策

最後更新：2026年9月15日

JustPICK（「我們」）營運 JustPICK 手機應用程式（「本 App」），一個協助使用者決定煮甚麼或去邊度食嘅餐點決策助手。本私隱政策說明我們收集甚麼資料、如何使用、與誰分享，以及閣下可享有的選擇及權利。下載、存取或使用本 App，即表示閣下同意本私隱政策所述之慣例。

本私隱政策僅適用於本 App，並不適用於第三方網站、產品或服務，即使該等網站、產品或服務於本 App 內連結或可存取亦然。

1. 我們收集的資料

1.1 閣下向我們提供的資料

  • 帳戶資料 — 當閣下使用 Google 登入時，我們會從 Google 取得閣下的姓名、電郵地址及個人頭像。
  • 偏好設定 — 菜系偏好、飲食限制、敏感食材排除設定、可用廚具、家庭人數，以及其他閣下輸入以個人化推薦內容的設定。
  • 閣下提交的相片 — 閣下為「落廚連續紀錄」打卡而拍攝的相片，以及閣下自願提交的餐廳餐牌相片，經審核後或會展示予其他使用者。
  • 已儲存內容 — 閣下於本 App 內儲存的食譜、餐廳及購物清單項目。
  • 通訊記錄 — 如閣下聯絡我們客服，我們會收集閣下訊息的內容及聯絡資料。

1.2 自動收集的資料

  • 使用數據 — 使用過的功能、瀏覽過的畫面、使用時長及互動模式（例如拒絕的餐點或生成的食譜）。
  • 裝置資料 — 裝置型號、作業系統及版本、獨有裝置識別碼及 App 版本，用於錯誤報告及故障排查。
  • 大約或精確位置 — 當閣下使用「出街食」模式時，我們會（視乎閣下授予的權限）存取閣下裝置的位置，透過 Google Places API 尋找附近餐廳。閣下不使用「出街食」模式時，我們不會收集位置資料。

1.3 我們不會收集的資料

我們不會蓄意收集政府身份識別號碼、財務帳戶詳情，或精確的健康或醫療紀錄。閣下輸入的敏感食材及飲食偏好屬自行申報性質，僅用於篩選本 App 內的推薦內容 — 詳見第 8 節。

2. 我們如何使用閣下的資料

我們收集的資料用於：

  • 提供、營運及個人化本 App 的核心功能（喺屋企煮、出街食、九大簋、已儲存餐點、購物清單、落廚連續紀錄）；
  • 生成 AI 驅動的餐點、食譜及餐廳推薦；
  • 將閣下的敏感食材及飲食排除設定套用於推薦內容；
  • 於不同時段及裝置間維持閣下的帳戶、偏好及已儲存內容；
  • 審核使用者提交的餐廳餐牌相片，然後才向其他使用者展示；
  • 診斷錯誤、監察效能及改善本 App；
  • 就閣下的帳戶、支援請求或政策重大變更與閣下溝通；
  • 履行法律責任及執行我們的使用條款。

我們不會使用閣下的資料作出對閣下產生法律或類似重大影響的自動化決策。

3. 處理資料的法律依據

JustPICK 於加拿大營運，並按照《個人資訊保護及電子文件法》（PIPEDA）及適用的省級私隱法例處理個人資料。除法律容許或要求外，我們僅在閣下知悉及同意（明示或透過閣下使用本 App 而默示）下收集、使用及披露個人資料。如閣下身處加拿大以外地區，我們會基於閣下的同意、履行我們與閣下之間的合約（提供本 App 服務），以及在適用情況下遵守法律責任，處理閣下的資料。

4. 第三方服務

我們依賴以下第三方服務供應商營運本 App，各供應商均有其自身的私隱政策規管其處理閣下資料的方式：

  • Google Sign-In — 身份驗證（姓名、電郵、頭像）。
  • Supabase — 後端資料庫、身份驗證及檔案儲存，包括餐牌及打卡相片。
  • Google Places API／地理編碼 API — 餐廳搜尋及基於位置的推薦。
  • Google Gemini API — AI 生成的食譜、餐點及餐廳推薦，透過 Supabase Edge Function 代理存取；閣下的提問內容及偏好或會傳送至 Google Gemini API 作處理。
  • Google AdMob — 一旦啟用後用於廣告（詳見第 10 節）。
  • RevenueCat — 一旦付費功能推出後，用於訂閱及應用程式內購買管理。
  • Instacart、Uber Eats、DoorDash、Amazon Associates — 可能於本 App 內出現的聯盟連結；點擊該等連結會將閣下帶往第三方網站，並受該第三方自身的私隱慣例約束。

我們不會將閣下的個人資料出售予第三方作其自身的營銷用途。

5. 資料保留

只要閣下的帳戶仍然有效，或基於提供本 App 服務所需，我們會保留閣下的個人資料。如閣下刪除帳戶，我們將於合理期間內刪除或匿名化閣下的個人資料，惟因履行法律責任、解決爭議或執行我們的協議而須保留者除外。已向其他使用者公開展示的餐牌相片，即使於帳戶刪除後，仍可能獲保留，惟會移除可直接識別身份的資料。

6. 資料儲存及跨境傳輸

閣下的資料使用 Supabase 及 Google Cloud 的基礎設施儲存，該等設施可能於加拿大以外地區（包括美國）儲存或處理資料。使用本 App，即表示閣下同意將其資料傳輸、儲存及處理於閣下居住國家以外的地方。我們會採取合理措施，確保閣下的資料無論於何處處理，均獲得足夠程度的保障。

7. 資料保安

我們採用合理的機構及技術保障措施，以保障閣下的個人資料，包括加密儲存及存取控制。然而，透過互聯網傳輸或電子儲存的方式，並無任何一種能夠做到百分之百安全，我們亦不能保證絕對的安全。閣下須自行負責妥善保管其裝置及帳戶登入資料的安全。

8. 敏感食材及飲食資料

閣下提供的敏感食材排除及飲食偏好設定，僅用於篩選及生成本 App 內的推薦內容。此等資料屬閣下自行申報性質，並非經專業人員驗證的醫療或健康資料。JustPICK 的敏感食材篩選功能屬便利性質，並非醫療安全系統 — 有關重要限制，詳見我們使用條款中的「敏感食材及飲食限制免責聲明」。除第 4 節所列的服務供應商（僅限於生成推薦內容所必需的範圍）外，我們不會將閣下的敏感食材或飲食資料分享予第三方。

9. 兒童私隱

JustPICK 並非以 13 歲以下兒童（或閣下所在司法管轄區規定的最低年齡以下人士）為對象，亦不擬供其使用。我們不會蓄意收集兒童的個人資料。如我們發現在未取得適當同意下收集了兒童的個人資料，我們將迅速刪除有關資料。如父母或監護人相信其子女曾向我們提供個人資料，請透過下方地址與我們聯絡。

10. 廣告及分析（未來功能）

我們現時並未展示第三方廣告。一旦啟用 Google AdMob，本政策將更新，說明用於廣告個人化的廣告識別碼及資料，屆時閣下可透過裝置設定管理廣告個人化。我們將按第 12 節就此變更作出通知。

  • 查閱我們持有關於閣下的個人資料；
  • 更正不準確或不完整的資料；
  • 要求刪除閣下的個人資料；
  • 撤回對我們處理閣下資料的同意，惟此舉可能限制閣下使用若干功能；

如欲行使上述任何權利，請聯絡 privacy@getjustpick.app。我們將於合理時間內按適用法律作出回覆。如閣下對我們的回覆不滿意，可聯絡加拿大私隱專員公署（priv.gc.ca）或閣下當地的資料保護機構。

我們可能因應慣例變化，或基於法律、營運或監管原因，不時更新本私隱政策。我們將更新上方「最後更新」日期，並就重大變更於本 App 內作出額外通知，例如於下次啟動時彈出提示。
